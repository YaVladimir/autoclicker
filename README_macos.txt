АВТОКЛИКЕР ДЛЯ macOS
====================

Первый запуск
-------------
1. Откройте install_macos.command двойным щелчком. Он установит единственный
   необходимый компонент для работы с системными возможностями macOS.
2. Затем откройте run_autoclicker_macos.command.
3. Откройте «Системные настройки» → «Конфиденциальность и безопасность» и
   включите для Terminal (или приложения Python, через которое вы запустили
   программу) «Универсальный доступ» и «Мониторинг ввода». Без них macOS не
   позволит отправлять клики и считывать глобальные горячие клавиши.

После изменения разрешений «Универсальный доступ» или «Мониторинг ввода»
полностью закройте и снова откройте автокликер.

Если macOS не откроет скачанное приложение, нажмите на нём правой кнопкой мыши,
выберите «Открыть» и подтвердите запуск. Первая публичная сборка не подписана
сертификатом Apple.

Быстрый старт для Cookie Clicker
--------------------------------
1. Оставьте режим «Под текущим курсором»: по умолчанию установлены 100 кликов/с
   и нулевая задержка.
2. Перейдите в игру и наведите указатель на печенье.
3. Нажмите F6. При нулевой задержке клики начнутся сразу.
4. F6 ставит кликер на паузу и продолжает сеанс, F8 останавливает всё.

При запуске кнопкой «Запустить» в режиме «Под курсором» и нулевой задержке
приложение даст три секунды, чтобы перевести указатель на цель. При
продолжении кнопкой тоже есть три секунды; продолжение через F6 — сразу.

Для фиксированной точки нажмите F7 или «Выбрать точку». Окно скроется:
щёлкните по цели на любом мониторе. Esc или F8 отменяют выбор и сохраняют
прежнюю точку. Сам щелчок выбора не передаётся игре.

Горячие клавиши
---------------
F6 — запуск, пауза и продолжение автокликера; во время отсчёта — отмена.
F7 — выбрать фиксированную точку щелчком по экрану.
F8 — полная остановка; во время выбора точки — отмена.

В macOS-версии их можно заменить через кнопку «Горячие клавиши…»: для каждого
действия доступна отдельная клавиша F1–F12. На MacBook может потребоваться
удерживать Fn, если F-клавиши управляют системными функциями.

Выбор сохраняется для текущего пользователя и не пропадает при обновлении
приложения.

Скорость, задержка и кнопка мыши тоже сохраняются после успешного запуска.

Окно и оформление
-----------------
Скорость можно менять ползунком, числом или кнопками 10 / 20 / 50 / 100.
Размер окна можно менять. Если места мало, настройки прокручиваются,
а кнопки запуска и остановки остаются внизу окна.
Кнопка «Вид…» позволяет выбрать системную, светлую или тёмную тему и
синий, фиолетовый или зелёный акцент. Выбор сохраняется после перезапуска.

Поиск золотых и красных печенек в этой macOS-версии ещё не подключён.
Для проверки нативного окна откройте test_macos_ui.command.
Подробный список ручных проверок: docs/MACOS_CHECKLIST.md.

Важно
-----
• На MacBook F6–F8 могут требовать удерживать Fn, если в настройках клавиатуры
  включены специальные действия клавиш.
• В некоторых играх автоматизация запрещена правилами. Используйте программу
  только там, где это разрешено.

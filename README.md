# Cookie Clicker Autoclicker

Небольшой автокликер с графическим интерфейсом для Cookie Clicker и других
игр-кликеров. Работает под Windows и macOS, умеет кликать под текущим курсором
или в сохранённую точку.

> Используйте автоматизацию только там, где это разрешено правилами игры или
> сервиса.

## Возможности

- от 1 до 100 кликов в секунду;
- задержка перед стартом;
- левая, правая или средняя кнопка мыши;
- глобальные горячие клавиши;
- сохранённая точка клика;
- нативный интерфейс macOS для светлой и тёмной темы.

## Быстрый запуск

### macOS

1. Откройте `install_macos.command` двойным щелчком.
2. Откройте `run_autoclicker_macos.command`.
3. В разделе «Конфиденциальность и безопасность» разрешите Terminal или
   Python доступ к «Универсальному доступу» и «Мониторингу ввода».

По умолчанию: F6 — запуск/пауза, F7 — сохранить точку, F8 — стоп. На MacBook
может потребоваться удерживать Fn.

### Windows

Установите Python 3 с Tkinter и дважды щёлкните `run_autoclicker.bat`.

## Установка для разработки

```bash
git clone <адрес-репозитория>
cd autoclicker
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[macos]'
python autoclicker_macos.py
```

Для Windows отдельные дополнительные пакеты не нужны.

## Проверки

```bash
python -m unittest discover -s tests
```

Тесты проверяют логику настроек и запуск движка кликов, не выполняя реальных
нажатий мышью и не требуя разрешений macOS.

На залогиненном Mac можно дополнительно проверить настоящее нативное окно:

```bash
RUN_MACOS_UI_SMOKE=1 python -m unittest tests.test_macos_ui_smoke -v
```

Smoke-тест показывает окно Cocoa, проверяет его видимость, наличие ключевых
контролов и то, что режим «Поверх других окон» выключен по умолчанию. Он не
запускает кликер или глобальные клавиши.

Для запуска без терминала откройте `test_macos_ui.command` двойным щелчком.

## Структура

| Путь | Назначение |
| --- | --- |
| `autoclicker.py` | версия для Windows |
| `autoclicker_macos.py` | логика версии для macOS |
| `macos_cocoa_ui.py` | нативное окно macOS на Cocoa |
| `tests/` | автоматические проверки |
| `install_macos.command` | установка macOS-зависимостей |
| `run_autoclicker_macos.command` | запуск macOS-версии |

# Cookie Clicker Autoclicker

Небольшой автокликер с графическим интерфейсом для Cookie Clicker и других
игр-кликеров. Работает под Windows и macOS, умеет кликать под текущим курсором
или в сохранённую точку.

> Используйте автоматизацию только там, где это разрешено правилами игры или
> сервиса.

## Возможности

- от 1 до 100 кликов в секунду; по умолчанию — 100;
- задержка перед стартом; по умолчанию — 0 секунд;
- левая, правая или средняя кнопка мыши;
- глобальные горячие клавиши, которые можно назначить на F1–F12;
- сохранённая точка клика;
- поиск золотых печенек на Windows: OpenCV отсекает знакомые иконки, выделяет
  золотую цель на жёлтом фоне и проверяет светлые цели по рисунку печеньки;
- отдельное включение ловли злых (красных) печенек на Windows;
- изменяемый размер окна Windows, прокрутка настроек и всегда видимые кнопки запуска и остановки;
- нативный интерфейс macOS для светлой и тёмной темы.

## Скачать приложение

Готовые файлы появляются на странице [Releases](https://github.com/YaVladimir/autoclicker/releases):

| Система | Файл | Что сделать |
| --- | --- | --- |
| macOS | `Автокликер-macOS.zip` | Распаковать и перетащить «Автокликер» в «Программы». |
| Windows | `Автокликер.exe` | Скачать и запустить. Установка Python не нужна. |

В Windows-сборку уже включены OpenCV и компоненты захвата экрана. Файл
`install_windows.bat` нужен только при запуске из исходников.

На macOS приложение попросит разрешить «Универсальный доступ» и «Мониторинг
ввода»: без них система не позволяет приложению выполнять клики и читать
горячие клавиши.

Сборка пока не подписана платным сертификатом Apple. Если macOS заблокирует
запуск, нажмите на приложении правой кнопкой мыши, выберите «Открыть» и
подтвердите запуск один раз.

## Запуск из исходников

### macOS

1. Откройте `install_macos.command` двойным щелчком.
2. Откройте `run_autoclicker_macos.command`.
3. В разделе «Конфиденциальность и безопасность» разрешите Terminal или
   Python доступ к «Универсальному доступу» и «Мониторингу ввода».

По умолчанию: F6 — запуск/пауза, F7 — сохранить точку, F8 — стоп. В macOS-версии
их можно изменить через кнопку «Горячие клавиши…». На MacBook может потребоваться
удерживать Fn.

Настройки клавиш macOS сохраняются в папке пользователя `Application Support`,
поэтому не пропадут после обновления приложения.

Скорость, задержка и кнопка мыши сохраняются после успешного запуска. На новом
компьютере приложение начинает с 100 кликов/с и нулевой задержки.

### Windows

Для обычного автокликера установите Python 3 с Tkinter и дважды щёлкните
`run_autoclicker.bat`.

Чтобы включить ловлю золотых печенек, один раз откройте
`install_windows.bat`. Он установит OpenCV и быстрый захват экрана.

1. Наведите курсор на основное печенье и нажмите `F7`.
2. Наведите курсор на один угол **только игровой области** (без вкладок,
   панели браузера, расширений и меню) и нажмите `F9`.
3. Наведите курсор на противоположный угол этой области и снова нажмите `F9`.
4. Выберите «Искать и ловить золотые печеньки» и/или «Искать и ловить злые печеньки (красные)», затем запустите `F6`.

Перед поиском программа примерно 0,75 секунды запоминает уже видимые яркие
иконки. Затем она ловит только новую круглую золотую цель, подтверждённую в
двух последовательных кадрах, нажимает её левой кнопкой и возвращает указатель
к основному печенью. Выбранная для обычных кликов кнопка на это не влияет.
Красные wrath cookies ловятся только при включённой отдельной галочке.
Можно ловить оба вида или только один. Красные цели дополнительно сверяются
с рисунком злой печеньки. Чем точнее выбрана область игры, тем меньше ложных срабатываний.

Если золотая печенька сливается с обычными печеньями фона или перекрывает
рамки и иконки, поиск дополнительно выделяет её светлые блики и круглый край.
Затем он сверяет рисунок с образцом при разных размерах и поворотах.
Образец включён в Windows-сборку.

## Сборка приложения

Сборка выполняется на целевой системе — macOS-приложение на Mac, Windows-файл
на Windows. Это позволяет включить системные компоненты корректно.

```bash
# macOS
python -m pip install -r requirements-build.txt -r requirements-macos.txt
pyinstaller --noconfirm build_macos.spec

# Windows
py -3 -m pip install -r requirements-build.txt -r requirements-windows.txt
pyinstaller --noconfirm build_windows.spec
```

Готовые файлы будут в папке `dist/`. При отправке тега вида `v1.1.0` GitHub
соберёт оба варианта и создаст черновик релиза автоматически.

## Установка для разработки

```bash
git clone <адрес-репозитория>
cd autoclicker
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[macos]'
python autoclicker_macos.py
```

В Windows активируйте окружение командой `.venv\Scripts\activate`, установите
`pip install -e ".[windows]"` и запустите `python autoclicker.py`.

## Проверки

```bash
python -m unittest discover -s tests
```

Тесты проверяют настройки, запуск движка, распознавание на реальных кадрах
Cookie Clicker при разных масштабах, выбор золотых и злых печенек и безопасную
остановку поиска. Реальные нажатия мышью они не выполняют.

Проверка расположения кнопок Windows при масштабах 100%, 150% и 200%:

```powershell
$env:RUN_WINDOWS_UI_SMOKE = "1"
python -m unittest tests.test_windows_ui_smoke -v
```

Эта проверка показывает тестовые окна, но не включает клики и глобальные клавиши.

На залогиненном Mac можно дополнительно проверить настоящее нативное окно:

```bash
RUN_MACOS_UI_SMOKE=1 python -m unittest tests.test_macos_ui_smoke -v
```

Smoke-тест показывает окно Cocoa, проверяет его видимость, наличие ключевых
контролов и то, что режим «Поверх других окон» выключен по умолчанию. Он не
запускает кликер или глобальные клавиши.

Для запуска без терминала откройте `test_macos_ui.command` двойным щелчком.

## Структура

| Путь | Назначение |
| --- | --- |
| `autoclicker.py` | версия для Windows |

| `install_windows.bat` | установка компонентов OpenCV для Windows |
| `autoclicker_macos.py` | логика версии для macOS |

| `run_autoclicker_macos.command` | запуск macOS-версии |

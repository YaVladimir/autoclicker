# Проверка переноса изменений 1.2.0 на macOS

Подготовлены управление сеансом, выбор точки щелчком, обновлённое нативное
окно, оформление и иконка приложения. Проверки логики выполняются без macOS.
Настоящее окно, разрешения, клики и сборку необходимо проверить на Mac.
Этот документ не подтверждает прохождение ручных проверок.

Поиск золотых и красных печенек — следующий этап после проверки базовой версии.
Существующий тег v1.2.0 не изменяется; перед новым выпуском нужно назначить
новый номер версии в pyproject.toml и build_macos.spec.

## Автоматическая проверка на Mac

Установить зависимости через install_macos.command, затем запустить
test_macos_ui.command. Если используется виртуальное окружение, активировать
его и выполнить:

```sh
python -m unittest tests.test_macos_core tests.test_macos_controller -v
RUN_MACOS_UI_SMOKE=1 python -m unittest tests.test_macos_ui_smoke -v
```

Проверка окна использует временные настройки и не отправляет реальные клики.
В GitHub настроены проверки логики и импорта Cocoa на macOS; проверка окна
требует активного рабочего стола и выполняется отдельно.

## Управление

- [ ] Первый запуск: 100 кликов/с, задержка 0, левая кнопка, режим под курсором.
- [ ] F6 запускает сразу при нулевой задержке; повторное нажатие ставит на паузу,
  следующее продолжает прежний сеанс без задержки.
- [ ] Кнопки запуска и продолжения под курсором дают время перевести указатель:
  при старте с нулевой задержкой — 3 секунды, при продолжении — 3 секунды.
- [ ] Заданная задержка старта, например 1,5 секунды, соблюдается и для кнопки,
  и для горячей клавиши. F8 отменяет отсчёт; клики после отмены не начинаются.
- [ ] F8 завершает сеанс, разблокирует настройки и сбрасывает паузу.
- [ ] Закрытие окна во время работы или отсчёта останавливает клики.
- [ ] Во время паузы нельзя поменять цель или настройки действующего сеанса.
- [ ] Левая, правая и средняя кнопки работают на подходящей тестовой цели.

## Выбор точки и мониторы

- [ ] F7 и «Выбрать точку» скрывают главное окно и показывают подсказку.
- [ ] Первый щелчок выбирает точку, не нажимая элемент под ней.
- [ ] Esc и F8 возвращают окно и сохраняют предыдущую точку и режим.
- [ ] F6 во время выбора не запускает клики.
- [ ] Фиксированные клики попадают точно в выбранную цель на Retina.
- [ ] Повторить на внешнем мониторе, расположенном слева и выше основного,
  а также на мониторах с разным масштабом.
- [ ] Проверить выбор в полноэкранном приложении и на другом рабочем столе.

## Окно и настройки

- [ ] На минимальном размере 580 × 360 кнопки запуска и остановки видны,
  настройки прокручиваются; элементы не перекрываются.
- [ ] После увеличения окна нет обрезанных надписей и лишней горизонтальной прокрутки.
- [ ] Ползунок, ручной ввод и быстрые значения скорости согласованы.
- [ ] Светлая, тёмная и системная темы читаемы; системная реагирует на смену темы macOS.
- [ ] Все три акцентных цвета различимы; оформление восстанавливается после перезапуска.
- [ ] Изменение оформления не сбрасывает горячие клавиши и настройки кликов.
- [ ] «Поверх других окон» выключено при запуске и включается по запросу.

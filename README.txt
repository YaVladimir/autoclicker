АВТОКЛИКЕР ДЛЯ WINDOWS
======================

Запуск
------
Самый простой способ — скачать «Автокликер.exe» со страницы Releases в GitHub
и запустить его: Python для этого не нужен.

Для запуска из исходников установите Python 3 с Tkinter, один раз запустите
install_windows.bat, затем запускайте run_autoclicker.bat.
Кнопка «Вид» открывает выбор светлой, тёмной или системной темы и акцентного
цвета. Выбор сохраняется. Скорость можно менять ползунком, вводом числа
или готовыми кнопками 10 / 20 / 50 / 100.

Быстрый старт для Cookie Clicker
--------------------------------
1. Оставьте режим «Под текущим курсором».
2. По умолчанию стоит 100 кликов/с и нулевая задержка; при необходимости измените их.
3. Перейдите в игру и наведите курсор на печенье.
4. Нажмите F6. По умолчанию клики начнутся сразу.
5. F6 ставит клики на паузу; F8 завершает сеанс. При запуске кнопкой с нулевой
   задержкой программа даст три секунды, чтобы перейти к цели.

Ловля золотых печенек
---------------------
В готовом «Автокликер.exe» необходимые компоненты уже установлены. Файл
install_windows.bat нужен только при запуске программы из исходников.

1. Нажмите F7 или «Выбрать точку», затем щёлкните по основному печенью на
   полноэкранном слое. Esc отменяет выбор.
2. Нажмите F9 или «Выбрать игровую область» и протяните рамку вокруг игрового поля.
3. Раскройте блок «Cookie Clicker», включите золотые и/или красные печеньки
   и запустите клавишей F6.

Золотая печенька всегда нажимается левой кнопкой. После этого курсор
возвращается к основному печенью. Злые (красные) печеньки ловятся при включении
отдельной галочки и тоже нажимаются левой кнопкой.

Размер окна можно менять. На небольшом экране настройки прокручиваются,
а кнопки запуска и остановки остаются внизу окна.

Горячие клавиши
---------------
F6 — запустить, поставить на паузу или продолжить автокликер.
F7 — открыть выбор фиксированной точки щелчком по цели.
F8 — остановить обычные клики и поиск золотых печенек.
F9 — выделить игровую область перетягиванием рамки.

Важно
-----
• Готовая сборка работает в Windows 10/11. Python с компонентом Tkinter нужен
  только при запуске исходников.
• В некоторых играх автоматизация запрещена правилами. Используйте автокликер только там,
  где это разрешено.
• Если игра запущена от имени администратора, автокликер тоже может потребовать запуск
  от имени администратора.

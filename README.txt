АВТОКЛИКЕР ДЛЯ WINDOWS
======================

Запуск
------
Самый простой способ — скачать «Автокликер.exe» со страницы Releases в GitHub
и запустить его: Python для этого не нужен.

Для запуска из исходников установите Python 3 с Tkinter и дважды щёлкните
run_autoclicker.bat.

Быстрый старт для Cookie Clicker
--------------------------------
1. Оставьте режим «Под текущим курсором».
2. Выберите скорость, например 20 кликов/с.
3. Перейдите в игру и наведите курсор на печенье.
4. Нажмите F6. По умолчанию клики начнутся через 2 секунды.
5. Для остановки нажмите F6 или F8.

Горячие клавиши
---------------
F6 — включить или выключить автокликер.
F7 — запомнить текущую позицию курсора и выбрать режим фиксированной точки.
F8 — аварийная остановка обычных кликов.

Важно
-----
• Готовая сборка работает в Windows 10/11. Python с компонентом Tkinter нужен
  только при запуске исходников.
• В некоторых играх автоматизация запрещена правилами. Используйте автокликер только там,
  где это разрешено.
• Если игра запущена от имени администратора, автокликер тоже может потребовать запуск
  от имени администратора.
